# Glossário

Os termos que aparecem no app e nesta documentação, em ordem alfabética. Cada termo leva à página que o explica em detalhe.

## Termos

| Termo | O que significa | Saiba mais |
|---|---|---|
| Agendamento | Uma execução de fluxo de trabalho programada para se repetir, como "toda segunda às 8h". | [Fluxos e agendamentos](/docs/workflows) |
| Agente | Um assistente de IA com instruções, modelo e ferramentas próprios. Há agentes da plataforma, da organização e de módulos. | [Agentes e habilidades](/docs/agents) |
| Aprovação | Um pedido para uma pessoa autorizar uma ação sensível antes de ela acontecer, como uma ferramenta que altera dados. | [Aprovações](/docs/approvals) |
| Assistente | O chat de IA do projeto. Abre em página própria ou no painel à direita da tela. | [Assistente (chat)](/docs/chat) |
| Auditoria | O registro de quem fez o quê na organização, com data, ação, alvo e resultado. Mostra os campos alterados, nunca os valores. | [Auditoria](/docs/audit-log) |
| Avaliação (eval) | Um conjunto de casos de teste que mede a qualidade das respostas de um agente, com notas. | [Avaliações](/docs/evals) |
| Base de conhecimento | Os documentos e páginas que a organização envia para o assistente consultar e citar. | [Base de conhecimento](/docs/knowledge) |
| Chave de API | Uma credencial para outro sistema chamar o app pela API `/v1`, sem uma pessoa conectada. | [Chaves de API e integração](/docs/api-keys) |
| Citação (fonte) | A indicação, na resposta do assistente, de qual documento da base de conhecimento sustenta o que foi dito. | [Assistente (chat)](/docs/chat) |
| Coleção | Um grupo de documentos da base de conhecimento. | [Base de conhecimento](/docs/knowledge) |
| Conector | Uma ligação com um sistema externo (API, banco de dados ou servidor MCP) que dá ferramentas novas aos agentes. | [Conectores](/docs/connectors) |
| Convite | Um link que dá acesso a uma organização ou a um projeto, com os papéis escolhidos por quem convidou. | [Membros e convites](/docs/members) |
| Dispositivo | Um equipamento compartilhado, como o computador da recepção, ativado com um código e ligado à organização. | [Dispositivos e app desktop](/docs/devices) |
| Equipe da plataforma (staff) | As pessoas que operam o app para todos os clientes. Só elas acessam `/admin`. | [Administração da plataforma](/docs/admin) |
| Execução (run) | Uma vez em que um fluxo de trabalho rodou, com estado, etapas e resultado. | [Fluxos e agendamentos](/docs/workflows) |
| Ferramenta | Uma ação que um agente pode executar, como buscar na base de conhecimento ou chamar um conector. | [Agentes e habilidades](/docs/agents) |
| Fluxo de trabalho (workflow) | Uma sequência de etapas automáticas, que pode incluir IA e pausas para aprovação. | [Fluxos e agendamentos](/docs/workflows) |
| Habilidade (skill) | Um pacote de instruções que ensina um agente a fazer um tipo de tarefa. | [Agentes e habilidades](/docs/agents) |
| Membro | Uma pessoa com acesso a uma organização. | [Membros e convites](/docs/members) |
| Modelo | O modelo de IA de um provedor que gera as respostas. A equipe da plataforma escolhe o modelo de cada função. | [Administração: IA](/docs/admin-ai) |
| Módulo | Um pacote de funcionalidades que se soma ao app, com páginas no projeto e, às vezes, configurações próprias. | [Módulos](/docs/modules) |
| Orçamento | O limite de consumo de IA da organização no período. | [Uso e orçamento](/docs/usage) |
| Organização | O espaço de uma empresa no app, com membros, papéis, projetos e configurações próprios. | [Organizações e projetos](/docs/organizations) |
| Papel | Um conjunto de permissões dado a membros: Proprietário, Administrador, Membro, Leitor ou um papel criado pela organização. | [Papéis e permissões](/docs/roles) |
| Permissão | O direito de fazer uma ação específica, como ver membros ou enviar mensagens ao assistente. | [Papéis e permissões](/docs/roles) |
| Plano | O pacote contratado pela organização, que define limites como orçamento e número de agentes. | [Administração: clientes](/docs/admin-customers) |
| Projeto | Uma área de trabalho dentro da organização. O assistente e os módulos funcionam dentro de um projeto. | [Organizações e projetos](/docs/organizations) |
| Rastro (trace) | O registro passo a passo de uma resposta ou execução: chamadas ao modelo, ferramentas usadas, tempo e tokens. | [Rastros](/docs/traces) |
| Recurso (flag) | Uma chave que liga ou desliga uma funcionalidade opcional, como a conversa por voz. | [Recursos (flags)](/docs/flags) |
| Sessão | Um acesso conectado à sua conta num navegador ou no app desktop. | [Seu perfil](/docs/profile) |
| Token | A unidade em que os modelos de IA medem texto. O custo de uma resposta depende dos tokens de entrada e de saída. | [Uso e orçamento](/docs/usage) |
| Unidade | Uma divisão do projeto, como uma filial ou um setor. | [Unidades](/docs/units) |
| Verificação em duas etapas | A confirmação por código, além da senha, que protege a conta. É obrigatória para a equipe da plataforma. | [Primeiros passos](/docs/getting-started) |
