## Decision 0016 — nonce vs fallback: **static fallback** (accepted, evidence in the decision)

Nonce build OK, nonce differs per request, but `/pt-BR/sign-in` is a Cache Components static shell
(`x-nextjs-postponed: 1`): 11 of 30 script tags had the nonce; the 18 prerendered chunk tags and the inline `$RT`
bootstrap did not, and Chromium blocked 19 scripts (log: scratchpad `csp-nonce-console.log`), the page never
hydrated. Switched to `cspMode: "static"` (`script-src 'self' 'unsafe-inline'`, Firebase + emulator `connect-src`,
no `unsafe-eval` outside dev). After that no CSP violation on any page visited. The nonce path stays implemented and
tested for later. Decision 0012 also got an "Outcome of Tasks 18–19" section.

## Concerns

1. **No commits** (permission). `pnpm-lock.yaml`/`pnpm-workspace.yaml` are shared with SP3 and desktop edits.
2. **All pages render at request time.** The shared shell reads `?unit=` (search params) at the root (display time
   zone), which under Cache Components cannot be prerendered, so the root layout awaits `connection()` inside
   `<Suspense>`; the static shell per locale is only the document + loading status. Fine for an authenticated app;
   moving `useCurrentNode` out of `ShellIntlProvider` would let more prerender.
3. **`/admin` for non-staff is the not-found page with HTTP 200** (streamed segment; `noindex`). Same as any unknown
   path under a locale, so the surface does not reveal itself, but there is no 404 status. A true 404 status needs the
   staff check before the shell flushes (not possible from a layout under Cache Components); if SP5/e2e require the
   status, the proxy would have to check it. `admin.spec.ts` (Task 23) should assert the not-found UI.
4. **Local env:** the workspace `.env.local` must gain `NEXT_PUBLIC_APP_ENV=local` (and ideally
   `NEXT_PUBLIC_MFA_FACTORS=phone`): the web now refuses to boot without it, the client bundle needs it. I passed them
   in my shell and did not edit the user's `.env.local`.
5. **Foreign processes:** a `next dev` of this app from another agent listens on 3101 (PID 55780), so a second
   `next dev` on 3100 was refused; I verified with `next build` + `next start --port 3100` (my process, stopped). The
   emulators on 9099/8080 were already running (not mine; left alone). Playwright created organizations
   "Acme Local" and "Beta Local" with project "Launch" in the emulator data.
6. **Parallel test load:** 12 client tests timed out (5 s) when turbo ran six packages' tests at once; alone the client
   suite passes 489/489. Worth raising timeouts or CI concurrency if it recurs.
7. `switchLocale` was unit-tested only (not exercised in the browser run); no favicon ships (404 in console).
