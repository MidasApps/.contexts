# SP4 — Chat: implementation plan

> **For agentic workers:** Use skill `using-ddc` before coding. Subagent-per-task with the
> templates in `.claude/skills/writing-plans-ddc/` (implementer + task-reviewer). Read
> `docs/plans/execution-constraints.md` first: **`.contexts/` and `.claude/` are read-only**.
> Progress: `docs/plans/2026-09-29-sp4-chat/progress.md`; reports:
> `docs/plans/2026-09-29-sp4-chat/reports/task-<N>.md`.

**Goal:** the shared chat (web + desktop): multi-agent streaming with delegation, tool calls,
reasoning and workflow steps; stop/resume; generative UI; inline approvals with audit;
history; uploads; voice — proven by Playwright e2e in `AI_MODE=fake`.

**Architecture:** `useChat` (AI SDK 7) + AI Elements in `@core/client` → `/v1/chat` (Bearer,
`conversations` context in `@core/services`) → `MastraGateway` → Mastra `chatRoute` v7 →
SP3 supervisor. Design: `docs/superpowers/specs/2026-09-29-sp4-chat-design.md` ("spec");
runtime: `docs/superpowers/specs/2026-09-29-sp3-agentic-runtime-design.md`; umbrella §8.

**Tech Stack:** MEMORY pins + spec §2 (2026-09-29): Node 26.10.0, Next 16.3.7, React 19.3.0,
Tailwind 4.3.3, shadcn CLI 4.21.0 (new-york, Radix), `ai` 7.0.122, `@ai-sdk/react` 4.0.125,
`@mastra/core` 1.71.0, `@mastra/ai-sdk` 1.10.5, `@mastra/client-js` 1.50.0, `streamdown` 2.6.0,
`recharts` 3.10.1, Zod 4.6.5, Vitest 5.0.2, Playwright 1.63.0.

## Global Constraints

- Same as SP3 plan "Global Constraints" (framework read-only + `framework-ok`, PATH export,
  port 3100 for web, pins via `catalog:` after `npm view`, `AI_MODE=fake` in every test,
  handler order, envelope, tenancy, file/function size, commit rules).
- Prerequisite: SP3 Tasks 0–29 done (gate green) and SP2 done (client package, shell,
  `SchemaForm`, `DataTable`, i18n, Playwright setup, desktop shell).
- Client rules: FSD layers (`@.contexts/engineering/architecture/fsd.md`), Atomic in
  `shared/ui` (`@.contexts/engineering/architecture/atomic-design.md`), no hard-coded copy
  (`@.contexts/engineering/rules/internationalization.md`), WCAG 2.2 AA
  (`@.contexts/engineering/rules/accessibility.md`), state per
  `@.contexts/engineering/rules/state-management.md` (server state via `useChat`/fetchers,
  Zustand only for UI prefs), tokens from `.design-system/DESIGN.md` (never invent tokens).
- Streaming rules: `@.contexts/engineering/rules/performance.md` §5 (TTFT < 1 s, abort
  propagation).
- Commit scopes: `chat`, `client`, `web`, `desktop`, `mastra`, `agents`, `contracts`,
  `services`, `i18n` (e2e specs use `test(chat)`).
