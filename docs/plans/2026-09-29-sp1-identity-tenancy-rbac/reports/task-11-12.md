## Task 12 — me, active organization, access context (`593ec6b`)

Under `packages/services/src/services/identity/`:

- Ports `UserRepository` (`get`, `ensure`, `updateProfile`, `setActiveOrganization`) and `AuthAccountReader`
  (profile + `mfaEnrolled` from `getUser().multiFactor`); adapters `firestore-user-repository` (`ensure` creates the
  doc on the first `GET /v1/me` and heals a partial doc by adding only missing top-level fields, one transaction,
  idempotent), `firebase-auth-account-reader`, `in-memory-user-repository`; `AccountMissingError` → 401.
- Use cases: `get-me`, `update-me` (null removes a regional preference; the IANA zone is validated by the contract;
  refused under impersonation), `set-active-organization` (`core.organization.read`, `lastContext = {organizationId}`,
  `ACTIVE_ORGANIZATION_CHANGED`, `syncClaims`; rate limit from the descriptor; refused under impersonation),
  `list-my-organizations` (live projections of the uid by `tenantId`, then the organizations), `resolve-access-context`.
- **`resolveAccessContext({ principal, node })`** — SP1 spec §10 signature, exported from `identity/index.ts`,
  `@core/services` and `CoreServer.resolveAccessContext`:
  `(input: { principal: Principal; node: NodeRef }) => Promise<ResolvedAccessContext | null>` with
  `ResolvedAccessContext = { tenantId; projectId?; unitId?; principal; permissions: readonly Permission[] (sorted);
  regional: { locale, displayTimeZone, nodeTimeZone, currency } }`. It authorizes `core.organization.read` at the
  node, then `getEffectivePermissions` and the regional settings (user preference → nearest node → organization;
  devices and API keys use the node's). `null` for the platform level, a non-member (fail-closed) or a missing
  chain; infrastructure errors reject. A fresh request scope per call. SP3 can replace
  `UNWIRED_REGIONAL_SETTINGS`/its interim adapter in `apps/mastra/src/runtime/access-port-binding.ts` with it.
  `GET /v1/me/context` uses `loadAccessContext` (same logic inside the request scope) and adds the organization,
  project and unit objects of the `AccessContext` view.
- Tenancy: `loadNode(node)` (chain loader, also used by `resolveRegionalSettings`) and `regionalSettingsAt`.
- `me-routes` (`GET|PATCH /me`, `PUT /me/active-organization`, `POST /me/claims/sync` — a failed sync answers 500
  after `claims_sync_failed` was logged, `GET /me/organizations`, `GET /me/context`); web routes `v1/me/**`.
- Index: access `principalId+isRevoked+tenantId`.

5. `11c2dff` Idempotency: one-time-secret endpoints store successes without body and replay 409 CONFLICT +
   `Location`; impersonated scope per session; attempt ids for complete/release; replayed errors carry the new
   request id.
6. `3d5270a` Owner hierarchy: update/revoke/remove require the target grant's permissions ⊆ the actor's (403
   `ESCALATION_FORBIDDEN`, descriptors updated).
