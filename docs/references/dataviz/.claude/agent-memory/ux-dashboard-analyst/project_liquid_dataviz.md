Liquid DataViz is a BI platform for real estate credit securitization portfolios. Client: Imcasa (Securitizacao Imobiliaria).

**Why:** Replaces fragmented spreadsheets/ERPs with unified dashboard for CFOs, credit analysts, and securitization teams.

**How to apply:** All UX recommendations must respect dark-mode-only theme (orange #F3A169, olive #576558, black #000000), Inter/Manrope fonts, Feature-Sliced Design architecture. 13 pages total, BigQuery backend with mock fallback.
