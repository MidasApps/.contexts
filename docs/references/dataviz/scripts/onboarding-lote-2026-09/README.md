**Exceção de nomenclatura.** Os identificadores desta pasta estão em português, fora
da regra de `.contexts/engineering/rules/development.md` ("Idioma dos identificadores").
Isso é uma exceção decidida em 2026-09-25, registrada na própria regra: a pasta não
entra na migração para inglês (`docs/plans/2026-09-25-english-identifiers.md`, Task 22)
nem na regra de lint que a encerra. Não acrescente código novo aqui. Um lote de
onboarding novo vai numa pasta nova, em inglês.
