Drop zones — Como o usuário sabe onde soltar?

A

Indicador de posição (linha azul)

Ao arrastar, aparece uma linha azul indicando onde o bloco vai cair — à esquerda, à direita, ou abaixo. Similar ao Notion.

B

Zona de drop com highlight

Ao arrastar sobre uma linha, a área inteira se destaca mostrando as posições possíveis (esquerda/direita/abaixo) com zonas coloridas.

C

Ghost preview

Uma sombra do bloco aparece na posição onde será solto, mostrando como o layout ficará antes de confirmar. Preview em tempo real.
