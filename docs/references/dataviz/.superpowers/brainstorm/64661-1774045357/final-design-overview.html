Resumo das Decisões

Toolbar: Flutuante acima, só no hover
Deletar: Botão X + modal de confirmação
Drag: Toolbar inteira é arrastável
Layout: Composição por linhas, max 3 cols
Drop: Linha azul como indicador
Tabela: Min 2/3 da largura
Seleção: Checkbox na toolbar, borda laranja
IA sem seleção: Layout + conteúdo
IA com seleção: Só conteúdo dos selecionados
