Design: Sub-Agentes Especialistas

Secao 2 de 5 — Cada agente com seu modelo, contexto e tools

SQL Agent Gemini 2.5 Pro — O mais poderoso. Consulta livre ao BigQuery.
SYSTEM PROMPT (contexto)
- Dicionario de dados completo (tabelas, campos, tipos, descricoes)
- Amostra de 5 rows por tabela
- Valores possiveis de campos categoricos (ratings A-H, faixas LTV, etc.)
- Convencoes: data_base_report = ultimo dia do mes, dataset = cliente ativo
- Regras SQL: sempre usar LIMIT, nunca DELETE/UPDATE/INSERT
- Formato de resposta: sempre incluir a query SQL executada
TOOLS
execute_sql(query: string) → rows[]
Executa SELECT no BigQuery. Read-only, timeout 30s, LIMIT 1000.

get_table_schema(table: string) → schema
Retorna schema detalhado de uma tabela (para queries complexas).

get_sample_data(table: string, n: number) → rows[]
Retorna N rows de amostra para entender o formato dos dados.
FLUXO (async generator)
yield "Analisando pergunta" → generateText → SQL → yield "Executando: SELECT..." → BigQuery executa → return { sql, rows, summary }
Business Agent Gemini 2.5 Flash — Especialista em securitizacao. Explica conceitos e regras.
SYSTEM PROMPT (contexto)
- Glossario completo de termos (PDD, LTV, rating, elegibilidade, etc.)
- Regras de negocio da securitizacao de credito imobiliario
- Escala de ratings Liquid (A=900-1000 ... H=0-299)
- Criterios de elegibilidade e grupos de repasse
- Formulas de calculo (PDD Liquid, PDD Bacen, pricing, desagio)
- Contexto regulatorio (Bacen, CVM)
TOOLS
lookup_glossary(term: string) → definition
Busca termo no glossario com contexto e formula.

get_business_rule(topic: string) → rule
Retorna regra de negocio detalhada sobre o topico.

get_indicator_definition(kpi: string) → definition
Retorna definicao, formula e interpretacao de um KPI.
Dashboard Agent Gemini 2.5 Flash-Lite — Le o estado atual. Rapido e barato.
SYSTEM PROMPT (contexto)
- Recebe o buildAIContext() completo do app-store
- Indicadores visiveis (KPIs, charts, tables) com valores atuais
- Filtros ativos (periodo, projetos, filtros avancados)
- Cliente ativo e dataset
- Pagina atual do dashboard
TOOLS
read_dashboard_state() → context
Retorna snapshot completo dos indicadores visiveis.

read_active_filters() → filters
Retorna filtros ativos com valores legíveis.

Nao precisa de generateText interno — contexto no prompt basta.
Comparison Agent Gemini 2.5 Pro — Analise temporal, tendencias, anomalias.
SYSTEM PROMPT (contexto)
- Metodologia de comparacao (MoM, YoY, range vs range)
- Metricas comparaveis e suas polaridades (positiveIsGood)
- Benchmarks do mercado imobiliario
- Formato de analise: destaque variacao %, direcao, significancia
TOOLS
compare_periods(table, p1, p2, metric) → variance
Compara metrica entre dois periodos.

get_kpi_history(metric, months) → timeseries
Retorna serie temporal de N meses para analise de tendencia.

detect_anomalies(metric, threshold) → anomalies[]
Identifica pontos fora do padrao na serie.
External Data Agent Gemini 2.5 Flash — Dados economicos, Selic, IPCA, mercado.
SYSTEM PROMPT (contexto)
- Indicadores economicos relevantes para securitizacao
- Fontes confiaveis (BCB, IBGE, B3, CVM)
- Formato: sempre citar fonte e data do dado
- Correlacoes conhecidas (Selic x inadimplencia, IPCA x correcao)
TOOLS
search_web(query: string) → results[]
Busca via Firecrawl com filtro de fontes confiaveis.

get_bcb_indicator(code: string, period) → series
API do Banco Central (Selic, IPCA, IGPM, cambio).
Export Agent Gemini 2.5 Flash-Lite — Gera relatorios PDF e planilhas.
SYSTEM PROMPT (contexto)
- Templates de relatorio disponiveis
- Formato padrao: header com logo + filtros + tabelas + graficos
- Regras de formatacao (moeda BRL, datas pt-BR, decimais)
TOOLS
generate_pdf(sections, filters) → url
Gera PDF com jsPDF + html2canvas. Retorna URL de download.

generate_csv(query_result, columns) → url
Converte resultado de query em CSV para download.
Simulation Agent Gemini 2.5 Pro — Cenarios what-if, stress test, projecoes.
SYSTEM PROMPT (contexto)
- Modelos de simulacao (pricing, PDD, elegibilidade, LTV stress)
- Parametros default e ranges aceitaveis
- Formulas de calculo (desagio, spread, delta_pdd)
- Cenarios historicos de referencia
- Sempre mostrar premissas assumidas
TOOLS
run_simulation(scenario, params) → results
Executa simulacao com parametros ajustados.

get_baseline(metric) → current_values
Busca valores atuais como baseline para comparacao.

execute_sql(query) → rows[]
Acesso ao BigQuery para buscar dados base da simulacao.
