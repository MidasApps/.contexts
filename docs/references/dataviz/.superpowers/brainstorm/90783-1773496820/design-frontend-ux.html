Renderizacao de Preliminary Results

Cada yield do async generator aparece como um step indicator no chat.

yield status Icone Label Extra info

Mudancas no AISidebar

Novo: ToolStepIndicator
Componente que renderiza a timeline de steps do agente.
Recebe array de preliminary results e mostra:
- Icone + label por status
- SQL preview expandivel (click to copy)
- Tempo decorrido por step
- Estado: loading (pulsa), done (check verde), error (vermelho)
Novo: InlineDataRenderer
Renderiza dados estruturados inline no chat:
- Tabelas (ate 10 rows, expandivel)
- KPI cards com variacao
- Links de download para exports
- SQL collapsible com syntax highlight
Atualizado: TOOL_LABELS
Mapa de labels expandido para os 7 agentes.
Cada agente tem icone, cor e label proprios.
Os status parciais (yield) tambem mapeados.
