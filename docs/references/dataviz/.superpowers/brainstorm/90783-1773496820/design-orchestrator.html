Decisoes de Design do Orquestrador

Modelo
Gemini 2.5 Flash-Lite — o orquestrador nao precisa raciocinar, so rotear. Custo: $0.075/1M input. Latencia minima.
System Prompt
Enxuto: descreve cada agente em 1-2 linhas. Inclui regras de roteamento (ex: "perguntas sobre contratos individuais → sql_agent"). Nao inclui contexto de negocio — isso fica nos sub-agentes.
Multi-Agent Chaining
O orquestrador pode chamar multiplos agentes em sequencia dentro dos 10 steps. Ex: "Compare inadimplencia com a Selic" → sql_agent → external_agent → sintese.
Context Passing
O body do request inclui: dashboard context (indicadores visiveis), dataset (cliente ativo), filters (periodo, projetos). Cada sub-agente recebe apenas o contexto que precisa.
