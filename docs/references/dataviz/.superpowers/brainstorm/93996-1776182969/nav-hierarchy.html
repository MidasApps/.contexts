Como organizar a navegação na sidebar?

Cada cliente tem grupos (MCMV, SBPE...) com relatórios dentro. Como mostrar isso?

A

Grupos como accordion no menu

Sidebar mostra os grupos como seções expansíveis. Clicar no grupo expande e mostra seus relatórios como sub-itens.
