Design System

Extraído diretamente do CSS de produção. Neutros frios, bordas hairline, raio generoso, paleta de status saturada. Dark-first com light theme paralelo.

Um sistema, vinte páginas.

Cada grupo do sistema agora vive na sua própria página — paleta, tipografia, componentes, motion, acessibilidade, voz, tokens. A sidebar à esquerda é o índice; o toggle Dark/Light persiste entre páginas.

A base é a mesma do produto: shell de 260px, tokens em styles.css, e cada página é um documento HTML independente — pronto para imprimir, compartilhar ou abrir isolado.
